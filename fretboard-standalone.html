Index: Setup and Advanced controls

What each control does and how to use it, in the order it appears in Setup. Advanced is the last card in Setup.

Diagram set
  • Number of diagrams or preset set: choose how many diagrams to show, or load Gauntlet, Multi-Instrument or All Keys. Loading a set replaces the diagram setups. Reselect the same set to reapply its preset.
  • Edit settings for: chooses which diagram the Selected diagram cards change. Use it to switch between diagrams before editing instrument, tuning, range and strings.
Selected diagram: instrument and tuning
  • Instrument model: sets the instrument for the selected diagram only. Applies immediately.
  • Open-pitch tuning preset: replaces the open pitches and the string/key count of the selected diagram.
  • Number of Strings: sets how many strings or keys the selected diagram has (1 to 20).
  • Tune down 1 semitone, Tune down half step, Tune up 1 semitone, Tune up half step: shifts every open pitch by one semitone. This does not transpose the selected key.
  • Reverse string/key order: reverses the pitches, note visibility and per-string limits together.
Fret window and range presets
  • First visible fret / Last visible fret: sets the visible neck window for the diagram.
  • Per-string range preset and Apply range preset: applies a built-in string or group fret range. Built-in presets use six-string numbering and can change the string count to 6.
  • Save current per-string limits: saves this diagram's per-string fret limits on this device. Tuning, visibility and the overall window are not saved.
Selected diagram: individual strings or keys
  • String (picker): shows one string row at a time. Choose a string to edit its row; every row still applies.
  • Open pitch: the note each string plays at fret 0.
  • Show notes: hides that string's note markers. The string line stays.
  • From fret / To fret: limits the note markers on that string. 0 includes the open note.
  • Piano, harp and koto reference maps ignore fret windows and capo.
Other diagrams: individual strings or keys
  • Edits the string rows of the other diagrams directly, without switching the editor. Key, Type and Selection stay under each fretboard.
Key, type and selection (one card per diagram)
  • Diagram title: a name for that diagram (40 characters max). It appears on exports.
  • Key: the root key of the diagram.
  • Type: the pattern family, for example scales, chords, intervals or custom patterns.
  • Selection: the pattern inside the chosen Type.
Diagram N - Strings (other diagrams)
  • Open pitch, Show notes, From fret and To fret for each string of a diagram that is not being edited. Same controls as Selected diagram: individual strings.
Export: Format and scope, Create export
  • Format and scope: picks what to export. Options are grouped as PDF (selected diagram, slideshow, all intervals, chords, scales or custom patterns), Images (JPG or PNG of the selected diagram, or each slideshow item), ZIP packages (scales, chords, intervals, gamuts, MIDI, circle-of-fifths sets), and Word documents (many layout versions). The full list is in Advanced > Export.
  • Create export: runs the chosen option. Nothing is exported until you press it.
Output
  • Info label: adds the key and pattern label to JPG exports. Same as Advanced > Appearance > Include Key/Pattern info in JPGs.
  • Key and pattern only: uses a shorter label (Simple Export Text).
  • Instrument, Tuning, Key, Type, Name, Formula: choose which fields the detailed image label shows. Saved on this device. The title prompt takes precedence.
  • Header text / Footer text: up to 80 characters printed at the top and bottom of exports.
Play through keys
  • Seconds per key: the minimum time spent on each key. Starting at C, the selected pattern is played through 12 keys by fifths or fourths. A longer pattern finishes first. The key returns to its starting value when stopped.
Slideshow playback
  • Add to Slideshow: saves the current diagram as a slide.
  • Slideshow BPM: metronome tempo. Each measure is 4 beats, so at 60 BPM one measure lasts 4 seconds.
  • Duration (measures): how many measures each slide stays on screen.
  • Loop: repeats the slides when the last one ends.
  • Play slideshow: advances through the slides with metronome clicks. It does not play a melodic exercise.
Slideshow files
  • Export all: exports the saved slides as images or a PDF.
  • CSV template and CSV import / export: saves or loads the slide list. The CSV holds slide data, not rendered images.
  • Clear: empties the slide list. Your saved patterns are kept.
Advanced
  • Expand all / Collapse all: opens every card in Advanced, or closes them all if all are open.
  • Advanced contains four panels: Board & Playback, Appearance, Export and New UI. Each panel and each section in it is a collapsed card.
Advanced > Board & Playback
  • Display Mode: the text shown on note markers.
  • Show fret numbers and Number background: show or hide the fret numbers, and choose the shape behind them.
  • Enable capo, Capo at fret, Capo style: place a capo on fretted diagrams. Keyboards and open-pitch maps ignore it.
  • Animate notes: pulses note markers during melodic exercises.
  • Start and end fret are in Setup, under Fret window.
Melodic exercises
  • Pattern preset: the degree sequence to play, using only the notes of Diagram 1, starting from the key.
  • Octave range: 1 to 3 octaves above the start. Each full pass through the notes rises an octave.
  • Chain length: plays up to 20 presets in a row, each an octave higher than the last.
  • Sequence override (degree sequence, e.g. 1 3 5 3): replaces the preset, except when the preset is Custom. Applies only when chain length is 1.
  • Tempo (BPM) and Play next note: plays the exercise, or advances one note at a time.
  • Export MIDI: saves this exercise as MIDI.
  • Export all keys: saves all 12 keys as a ZIP.
  • Family ZIP and Family MIDI: save every pattern in the Diagram 1 family as ZIP files, or as one combined MIDI.
Cycle through patterns
  • Cycle: replaces the slideshow with every pattern of the selected Type in the current key, then loops with metronome clicks. Custom patterns are not supported.
  • Shuffle: plays the same cycle in random order.
  • Stop or pause from Slideshow playback.
Reference pitches
  • Chromatic tuner: the tuner toggle. Reference notes do not use the microphone.
  • Show the playable piano with pattern highlights, or play reference notes at a chosen octave to tune by ear.
Colors and text size
  • Color Theme: marker and diagram colors.
  • Page Theme: the colors of the interface.
  • Base Font Size: the interface text size.
Custom patterns
  • Import (Pattern name | semitone code): for example "My Pattern | 024579B". Digits 0 to 9, A and B are semitones 0 to 11.
  • Import: adds the typed pattern. Import CSV loads a file.
  • All: copies all built-in patterns into custom patterns.
  • Delete all custom: removes every custom pattern.
Advanced > Appearance
  • Theory Info Display: Hide Title / Show Title hides the heading in the info panel. Show Info Panel opens the panel for the selected key and pattern.
  • Name, Root Note, Scale/Chord Spelling, Quality, Tonic Function, Dominant Function, Modes, Inversions, Description: check the details to show in the info panel. Some depend on the pattern Type. Hide About Section hides the about text.
  • Note markers: marker size, shape, label size, effect, gradient and vertical offset (px). These change drawing style, not the notes.
  • String lines: string height (base stroke), legacy string thickness, style, gradient, effect, gap between strings, opacity.
  • Fret lines: base fret width, style and rendered thickness.
  • Fret number labels: placement, alignment, text size and vertical offset. Positive moves down, negative moves up.
  • Position dots: placement and vertical offset of the fretboard position markers.
  • Force White Fretboard Background: overrides the diagram background color.
  • Custom colors: color pickers for intervals, notes, strings and frets. Use Gradient turns gradients on per group. Invert Colors inverts all custom pickers.
  • String Height / Fret Width: base stroke and width values (px).
  • Tempo and Play Pattern: sets the tempo (BPM) and plays the selected pattern.
  • Add to Slideshow: adds the current diagram to the slideshow.
  • Include Key/Pattern info in JPGs and Simple Export Text: control the labels on exported images.
  • Export selected diagram JPG: exports the current diagram.
Advanced > Export
  • Format and scope and Create export: the same export list as in Setup. Options cover PDF, JPG and PNG images, ZIP packages (scales, chords, intervals, gamuts, MIDI, circle-of-fifths sets, all-keys package), and Word documents (several layout versions, such as V2 with two spans, V7 minimalist and V8 theory focus).
  • Show older direct-export buttons: reveals the older single-purpose export buttons.
  • Detailed label fields: Instrument, Tuning, Key, Type, Name, Formula. Saved on this device.
  • Large library exports can take time. Stop cancels the All Keys package and may keep partial results for other exports.
Advanced > New UI

Optional study tools. Each card is collapsed.

Navigation
  • Switch diagram, Explore another key (random key), Explore another selection (random selection).
  • Move fret window: one fret lower or higher. Locate a visible root: jumps to a visible root.
Fretted-Note Study
  • Focus on a pitch and Focus on a string: show only one pitch or string.
  • Outline root notes, Conceal note labels, Reveal concealed labels on hover or focus.
Practice
  • Find a pattern pitch: picks a target pitch. Check the target pitch: shows or hides the answer.
  • Practice countdown and Completed repetitions: a timer and a counter.
  • Session notes: free text for the session.
Workspace
  • Save checkpoint / Restore checkpoint: keeps and reloads a local snapshot.
  • Copy text / Download .txt: a text practice sheet.
  • Reset view: resets New UI view preferences.
Accessibility & Spacing
  • Compact control spacing, Larger control text, Full-width input fields, Stronger keyboard focus outlines, Reduce interface motion.
Key Navigation, Fret Windows, Fretted-Note Filters, Labels, Styling
  • Key Navigation: Down and Up transpose the key by the chosen amount.
  • Fret Windows: Visible fret span, Start window at fret, Move window by octave, Fit currently visible notes, Show the full fret range.
  • Filters: Focus on an interval, Even or odd frets, String region (low, middle, high).
  • Labels: Override marker text with pitch names (sharp or flat); Use one marker fill color.
  • Styling: root marker size multiplier, non-root marker opacity (%), marker border width (px), root marker fill override.
Ear Training, Metronome, Practice Records, Diagram Bookmarks
  • Ear Training: Play root, Reveal pitch, and the New UI audio volume (%). A quiz asks which pitch you heard.
  • Metronome: Beats per bar and Tap tempo.
  • Practice Records: Log session, Download CSV, Clear records.
  • Diagram Bookmarks: save the selected diagram, load a bookmark into the selected slot, Copy pattern link (key, type and selection), Delete bookmark, and Clear notes.
Lab and More cards
  • Note-Location Quiz and Interval-Listening Quiz: Reveal without scoring.
  • Ordered Practice Routine: Add current, Next item, Earlier / Later, Remove item.
  • Visible-Note Routes: Download route CSV.
  • Tuning Reports: Capture tuning.
  • Workspace Utilities: Toggle groups, Download JSON of visible positions, Copy description, Print diagram.
  • Visible Triad Plan Finder: Maximum fret difference, Participating strings, Tone on the largest-numbered string.
  • Theory Reference, Pattern Harmony, Pattern Comparison, Practice Prompts, Pitch-Class Voice Leading, Chord Extensions and Shells, Rhythm and Pedal Studies, Triad-Quality and Scale-Degree quizzes, Pitch-Set Scratchpad, Saved Practice Analytics, and Tempo Milestones are study cards. Open each card for its controls.
Studio cards
  • Work and Rest Blocks: Work duration (seconds), Rest duration (seconds), Number of work rounds.
  • Study Checklist: Done / reopen, Remove task, Download checklist.
  • Pattern Study Notebook: Delete entry, Download notebook (JSON).
  • Exercise Audio Controls: tempo (BPM), articulation (Detached, Staccato, Legato), starting register, Stop exercises.
  • Melodic Exercises, Arpeggio Exercises, Pattern-Derived Progressions, Pitch-Set Structure, Mode and Scale Analysis, Visible Fretboard Geometry and Technique Drills are study cards. Open each card for its controls.
